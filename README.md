# just-volleyball-mods

Unofficial fan-made gameplay and quality-of-life mods for Just Volleyball, kept separate from the core loader and from textures or models.

**This is an unofficial fan project.** It is not affiliated with, endorsed by, or supported by the developers of Just Volleyball. Original work only. Never add official game files (the executable, `.pck`, or extracted game assets) here.

## Layout

Each published mod gets its own top-level folder:

```
<mod-name>/
  README.md      # what it does and how to install it
  CHANGELOG.md   # version history
  archive/       # superseded uploads, used when a later fix replaces a file already published
  ...mod files...
```

If a released file is later replaced by a fix, the old file is moved into that mod's `archive/` folder rather than deleted, so older references keep working.

## Status

No mods have been published yet.

## Install basics (once mods are published)

1. Install the unofficial core from https://github.com/Ashtonite365/just-volleyball-core (once that repository has a published release).
2. Close Just Volleyball.
3. Back up `mods` and follow the README inside the specific mod folder.
4. Keep your own configs and packs. Confirm the file hashes after copying.

Related repositories:

- Core / loader: https://github.com/Ashtonite365/just-volleyball-core
- Textures and models: https://github.com/Ashtonite365/just-volleyball-assets
